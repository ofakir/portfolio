01 · About me

A developer who learns fast and ships

I'm a full-stack web developer in training at ISTA NTIC Sidi Maarouf (graduating June 2026). I love the moment an idea turns into something real that works smoothly in the browser.

On the front end I work with HTML, CSS, JavaScript, React and Tailwind CSS. On the back end I use PHP, Python and MySQL to build complete products with accounts, data and dashboards, like my CAN 2025 predictions platform.

I care about clean, maintainable code. I use Git, GitHub and GitLab every day, work in Agile sprints with Jira, and have set up CI/CD pipelines with code-quality checks (SonarQube) to automate testing and deployment.
