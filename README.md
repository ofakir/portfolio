# Othmane Fakir — Portfolio

Personal portfolio of **Othmane Fakir**, Full-Stack Web Developer based in Casablanca.

**Live:** https://ofafolio.netlify.app/

Built from scratch with plain HTML, CSS and JavaScript. It has no framework and no build step.

- Dark and light themes (follows system preference, with a toggle)
- Fully responsive, accessible navigation and reduced-motion support
- Project filters, scroll animations, and SEO / link-preview tags

## Structure

```
index.html              page content
style.css               design tokens, layout and components
script.js               theme, menu, filters, animations, contact form
Othmane-Fakir-CV.pdf    downloadable CV
assets/img/             optimized images (WebP)
assets/icons/           skill icons (from Devicon, MIT)
```

To run locally, open `index.html` in a browser.
